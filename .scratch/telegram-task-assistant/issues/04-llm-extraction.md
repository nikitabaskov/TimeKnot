# 04 — Живой разбор текста и создание задачи

**What to build:** Владелец пишет «Купить корм коту завтра в 19:00» и получает подтверждение с распознанной сутью задачи и итоговой датой. Задача лежит в БД и видна в `/tasks`. Напоминание в назначенное время пока не приходит.

**Blocked by:** 03 — Граф и шов `handle_message` на фейковом LLM.

**Status:** ready-for-agent

- [ ] Реальная реализация LLM-клиента: OpenRouter через OpenAI-совместимый интерфейс, идентификатор модели из переменной окружения
- [ ] В промпт подаются текущие локальные дата, время и день недели
- [ ] Модель возвращает абсолютный ISO-8601; относительные выражения («через 45 минут», «в следующую среду») разрешает она, детерминированного парсера дат в проекте нет
- [ ] Полученный момент конвертируется в UTC и сохраняется
- [ ] Сообщение без времени («почитать книгу») создаёт задачу с пустым `due_at`
- [ ] Подтверждение показывает суть задачи и итоговую дату в локальном времени
- [ ] `/tasks` показывает задачи со сроком и без срока раздельно
- [ ] Тесты идут через шов `handle_message` с фейковым LLM; сеть в тестах не трогается
