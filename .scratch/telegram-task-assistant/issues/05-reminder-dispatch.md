# 05 — Напоминание срабатывает

**What to build:** Владелец создаёт задачу на «через две минуты» и через две минуты получает от бота сообщение. Пока процесс жив, напоминания приходят вовремя.

**Blocked by:** 04 — Живой разбор текста и создание задачи.

**Status:** ready-for-agent

- [ ] APScheduler на `AsyncIOScheduler` с `MemoryJobStore`; персистентный jobstore не используется
- [ ] Создание задачи со сроком ставит джоб; таблица `tasks` остаётся единственным источником правды
- [ ] Шов `dispatch_due` принимает текущий момент и возвращает отправленные напоминания
- [ ] Отправитель Telegram описан протоколом и подменяется в тестах
- [ ] Статус переводится **после** успешной отправки: доставка at-least-once, дубликат допустим, пропуск — нет
- [ ] Перед отправкой статус задачи перечитывается из БД; по закрытой задаче напоминание не уходит
- [ ] Задача с пустым `due_at` в планировщик не попадает
- [ ] Тесты гоняют `dispatch_due` на фиксированных часах
