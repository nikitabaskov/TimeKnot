# 12 — Golden-набор и прогон качества разбора

**What to build:** Появляется способ измерить качество разбора русского текста числом, а не ощущением. После этого смена модели или правка промпта перестают быть рулеткой: прогнал набор, увидел цифру, принял решение.

Делается после выхода MVP на реальных фразах — набор наполняется тем, на чём бот действительно спотыкался.

**Blocked by:** 11 — Деплой на VPS.

**Status:** ready-for-agent

- [ ] 50–100 русских фраз в YAML: текст, замороженное «сейчас», ожидаемые интент, суть задачи и абсолютный ISO-момент
- [ ] Набор покрывает: абсолютное время, относительное («через 45 минут»), дни недели («в следующую среду»), время суток («завтра вечером»), задачи без времени, все четыре интента
- [ ] В набор внесены фразы, на которых бот реально ошибался в эксплуатации
- [ ] Прогон в CI: через шов `handle_message` с фейковым LLM — проверяется код вокруг модели, сеть не трогается
- [ ] Ручной прогон по флагу: через шов `extract` с настоящей моделью — проверяется сама модель
- [ ] Отчёт показывает долю совпадений и поимённо перечисляет расхождения
- [ ] Отдельно выводится доля срабатываний ветки повтора — метрика стабильности JSON-схемы
- [ ] Amazon MASSIVE не используется: его слоты `date`/`time` — текстовые спаны, а не абсолютные моменты
