# 08 — Уточняющий диалог

**What to build:** Владелец пишет «напомни в 5», бот спрашивает «5 утра или 5 вечера?». Владелец отвечает обычным текстом — задача создаётся на нужный час. Если между вопросом и ответом бот перезапустили, диалог всё равно продолжается с той же точки.

**Blocked by:** 04 — Живой разбор текста и создание задачи.

**Status:** ready-for-agent

- [ ] Состояние графа персистится в `AsyncSqliteSaver` в том же файле БД, `thread_id = chat_id`
- [ ] Двусмысленное время останавливает граф через `interrupt` и отправляет вопрос
- [ ] Следующее сообщение пользователя возобновляет граф с точки остановки
- [ ] Уточнение задаётся не более одного раза на задачу; если ясности нет — задача сохраняется без срока, пользователю это сообщается
- [ ] Пользователь может бросить уточнение, написав что-то другое, и не застрять в диалоге
- [ ] Отдельного FSM в aiogram нет: состояние диалога хранится только в чекпойнтере
- [ ] Тест на рестарт: чекпойнтер переоткрывается новым экземпляром, диалог продолжается
